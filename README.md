# CK3 Workshop History

Historical tracking and reconstruction of selected Crusader Kings III Steam Workshop mods.

The project is currently in the research and historical reconstruction phase.

## Structure

- `analysis/` — research, analysis scripts and generated reports
- `mods/` — reconstructed canonical Workshop snapshots
- `metadata/` — Workshop event and snapshot metadata
- `config/` — tracked mod definitions and system configuration

The canonical Workshop history has not yet been constructed.
